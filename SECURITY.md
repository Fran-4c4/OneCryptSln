# Security policy

## Supported versions

There are no supported OneCrypt releases at this time. The source has not
completed a modern cryptographic, dependency or application-security audit.
Do not rely on current builds to protect sensitive information.

## Reporting a vulnerability

Do not open a public issue containing an exploit, credential, private key,
personal information or data derived from a real user. Use the repository's
private security-advisory channel when it becomes available.

Before the repository is made public, the maintainer must configure and test a
private reporting channel. Until then, retain vulnerability details privately.

See [the security design](docs/security.md) for current limitations and the
requirements applied to security-sensitive changes.
